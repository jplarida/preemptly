PreEmptly · LPG pre-order platform · Phase 1

Architecture Tree — apps/api-core

A greenfield, split-ready, multi-tenant backend: a cross-cutting kernel, a vertical-agnostic core-domain, and swappable domain packs — LPG is pack #1. Any module extracts into its own service later through four injected seams, with no business-logic rewrite.

The four seams — split-ready by design

1
Event bus  platform/events/bus.ts
Now: in-memory + outbox relay  ·  Later: NATS / BullMQ
2
Contract  <module>.contract.ts
Now: direct in-process call  ·  Later: HTTP/gRPC client, same interface
3
Repository  <module>.repository.ts
Now: shared Prisma on one Neon DB  ·  Later: module's tables move to its own DB
4
Pack registry  platform/registry/pack.ts
Now: mounts LPG  ·  Later: safety / health / home-services drop in as packs
